# PrepWise AI

AI-powered mock interview platform that simulates real interview experiences with voice interaction, dynamic questions, and intelligent feedback.

Practice smarter. Speak confidently. Improve faster.

---

## Features

- Role-based interviews (custom questions based on job + experience)
- AI evaluation (score, strengths, weaknesses, improvements)
- Voice interaction
  - Speech-to-text (answer using microphone)
  - Text-to-speech (AI reads questions aloud)
- Performance analytics (score trends & insights)
- Downloadable report (PDF)
- Real interview simulation (multi-question flow)
- Authentication with Supabase
- Interview history dashboard

---

## Tech Stack

| Layer        | Tech |
|-------------|------|
| Frontend     | Next.js (App Router), React, Tailwind CSS, Framer Motion |
| Backend      | Express.js (Node.js) |
| AI           | Groq API (llama-3.3-70b-versatile) |
| Database/Auth| Supabase |
| Voice APIs   | Web Speech API |
